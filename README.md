A pure-stdlib Python program that draws a newspaper front page summing up the world news of Saturday 21 November 2026 — Russian missiles landing in Poland, COP31 talks running into overtime, the Kryvyi Rih barrage, the JPMorgan / Visa / Mastercard data breach, Cyclone Akvan's rains over Odisha, and India's fightback in the Wellington Test — as one 1024x1024 image.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## The image

`main.py` draws the front page from scratch with the Python standard library only (a hand-built 5x7 bitmap font and a small PNG writer) and writes `entry.png`. Two runs produce byte-identical output. A rendered copy is included as `entry.png`.
